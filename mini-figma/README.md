# mini-figma

Мини-клон Figma: React + TypeScript + Tailwind CSS (Vite).

## Что работает на этом шаге

- Сетка на фоне, привязанная к мировым координатам канваса.
- Панорамирование: **Space** + перетаскивание мыши.
- Зум колесом от **10%** до **400%** вокруг курсора; при старте точка (0, 0) канваса — в центре экрана.
- Три панели-каркаса: инструменты (слева), свойства и слои (справа).
- Фигур пока нет — состояние (`useShapes`) и рендер одной фигуры (`Shape`) готовы к шагу 2.

## Архитектура

Каждая папка отвечает за свою часть:

| Папка | Что лежит | Зачем |
| --- | --- | --- |
| `src/types/` | `shape.ts` — Shape, Tool, координаты | единый «язык» проекта, типы ловят ошибки до запуска |
| `src/constants/` | `tools.ts` — список инструментов и клавиши R/O/V | раскладку меняем в одном файле |
| `src/utils/` | `geometry.ts` — пересчёт экран → канвас с учётом зума/панорамы | без него фигуры «уезжают» от курсора при зуме/панораме |
| `src/hooks/` | `useViewport.ts` (камера), `useShapes.ts` (данные), `useHotkeys.ts` (клавиши, заготовка) | камера, данные и клавиатура — три независимые заботы; компоненты остаются тонкими |
| `src/components/` | `Canvas`, `Shape`, `Toolbar`, `PropertiesPanel`, `LayersPanel` | один компонент — одна зона экрана |
